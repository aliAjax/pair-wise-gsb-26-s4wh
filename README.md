# hxwl-12 心理咨询个案记录 · 危机分级台账

按个案登记日期、风险级别与干预目标入账的危机分级台账，内置督导确认门、降级审核、结案冻结与更正留痕。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 台账限制规则

| 规则 | 内容 |
| ---- | ---- |
| R0 | 登记要素完整：日期、风险级别、干预目标、判断依据 |
| R1 | 高风险个案必须附安全计划（预警信号、应对策略、紧急联系人、危险物品限制） |
| R2 | 高风险会谈未经督导确认，下一次会谈不得落盘 |
| R3 | 风险降级须连续两次低风险评估并写明判断依据（上调立即生效，安全优先） |
| R4 | 结案后记录冻结，仅可追加更正 |
| R5 | 更正须保留原内容、更正原因和责任人 |

任何操作命中限制时，页面顶部冲突面板会展示：**个案、日期、风险级别、命中的限制**及说明。
重开个案时自动做一致性校验：个案、会谈、督导确认状态与更正记录须对应一致。

## 代码结构

- `src/domain/types.ts` — 领域模型（个案、会谈、安全计划、督导确认、更正、冲突）
- `src/domain/ledger.ts` — 规则引擎（纯函数）：登记、会谈落盘、督导确认、降级、结案/重开、更正、一致性校验
- `src/domain/seed.ts` — 种子数据，覆盖各规则典型场景
- `src/components/` — 台账表格、冲突面板、登记表单、个案详情（时间线/确认/降级/更正）
- `src/App.tsx` — 状态组装：操作成功入账，被拦截则展示冲突

## 种子数据演示路径

- **C-1024**（高风险）：末次高风险会谈待督导确认 → 新增会谈命中 R2；确认后可落盘
- **C-2031**（中风险）：仅一次低风险评估 → 申请降级命中 R3；再补一次低风险会谈后降级成功
- **C-3099**（已结案）：新增会谈命中 R4；可登记更正（原内容留痕）；重开后自动校验一致性
