# hxwl-12 心理咨询个案危机分级台账

把心理咨询个案记录做成**危机分级台账**：按登记日期、风险级别、干预目标管理个案，
覆盖高风险安全计划、督导确认闸门、风险降级条件、结案冻结、更正留痕与重开一致性核对。

## 技术栈

React 19 + Vite + TypeScript + 纯 CSS；规则层为无副作用纯函数，配 Vitest 自检。

## 本地运行

```bash
npm install
npm run dev        # http://localhost:5112
npm test           # 规则引擎 + 渲染冒烟（27 项）
npm run build      # tsc --noEmit + vite build
```

## 业务规则（全部在 `src/domain/rules.ts` 强制执行）

1. **登记三要素**：咨询师按「个案登记日期、风险级别、干预目标」登记；
   **高风险必须附完整安全计划**（预警信号、应对步骤、支持者、专业求助、环境安全五项），缺一不可
   —— 命中 `HIGH_RISK_SAFETY_PLAN_REQUIRED`。
2. **督导确认闸门**：上一次会谈未经督导确认，**下一次会谈不能落盘**
   —— 命中 `PERSIST_BLOCKED_PENDING_SUPERVISION`；确认需留督导姓名。
3. **风险降级**：必须**连续两次低风险**，且第二次低风险必须**写明判断依据**。
   第一次低风险为「观察期」，生效级别暂不下降；观察期内回升则重新计数；不允许高/中直接跳到中风险
   —— 命中 `DOWNGRADE_NEEDS_TWO_LOW` / `DOWNGRADE_BASIS_REQUIRED`。
4. **结案冻结**：全部会谈确认后方可结案；冻结后禁止直接修改/新增会谈
   —— 命中 `FROZEN_CASE_WRITE_BLOCKED`。
5. **更正留痕**：冻结后只允许更正，**原内容、更正原因、责任人**三项缺一不可，原文不被覆盖
   —— 命中 `CORRECTION_TRACE_REQUIRED`。
6. **重开一致性**：重开须填原因；核对个案状态、会谈落盘/确认链路、更正记录引用是否对应一致，
   冲突时展示**个案、日期、风险级别及命中的限制明细**
   —— 命中 `REOPEN_CONSISTENCY_BROKEN`。

## 角色

- **咨询师**：登记个案与会谈、提出更正、结案/重开；
- **督导**：确认会谈（确认后下一次会谈才允许落盘）；
- **机构管理员**：兼有上述操作并可做全局一致性核对。
